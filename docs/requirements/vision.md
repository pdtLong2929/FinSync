## 2. Product Vision Statement

**FOR** individuals and groups who need to manage personal finances and shared expenses  
**WHO** struggle with tracking spending, splitting bills, and maintaining group funds  
**THE** FinSync **IS A** mobile application  
**THAT** combines personal financial management (similar to *Money Lover*) with intelligent group expense splitting (similar to *Splitwise*), integrated with an AI financial advisor  
**UNLIKE** existing solutions that only focus on one aspect (either personal or group finance)  
**OUR PRODUCT** provides a unified platform with AI-powered spending analysis and budget optimization recommendations.

## 3. Target Audience

| User Type | Description |
|---|---|
| **Regular User** | Individuals managing personal wallets, transactions, budgets, savings goals, and participating in group expenses |
| **Administrator** | System administrators managing users, default categories, and viewing system-wide statistics |

## 4. Key Features Overview

| # | Feature Group | Description |
|---|---|---|
| 1 | Authentication & Security | Register, login, JWT, forgot/change password |
| 2 | Profile Management | Update info, avatar, default currency (VND, USD) |
| 3 | Wallet & Personal Account | Create bookkeeping wallets (cash, card, bank) |
| 4 | Personal Transaction Tracking | Record income/expense with receipt photos |
| 5 | Group Management & Shared Wallets | Create groups, invite via link/code |
| 6 | Smart Debt Split & Settlement | Split algorithms, debt board, reminders |
| 7 | Budget Planning & Alerting | Weekly/monthly budget limits, 80%/100% alerts |
| 8 | Financial Reporting & Analytics | Interactive charts, PDF/Excel export |
| 9 | Savings Goal Management | Long-term savings goals, progress tracking |
| 10 | System Administration | Admin panel for users, categories, stats |
| AI | AI Financial Advisor | Spending analysis & budget optimization |

## 5. Core Business Rule

> The system is purely a **manual bookkeeping, calculation, and reminder** tool — it does **NOT** connect to real bank accounts and does **NOT** automatically deduct user funds.
