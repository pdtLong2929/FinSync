# Use Cases

This directory contains detailed use case specifications organized by functional group.

## 10 Functional Groups

| # | Group | Key Use Cases |
|---|---|---|
| 1 | Authentication & Security | Register, Login, Forgot Password, Change Password |
| 2 | Profile Management | Update Profile, Change Avatar, Set Default Currency |
| 3 | Wallet & Personal Account | Create Wallet, View Total Assets, Manage Accounts |
| 4 | Personal Transaction Tracking | Record Income/Expense, Attach Receipt Photo, Categorize |
| 5 | Group Management & Shared Wallets | Create Group, Invite Members, Group Fund Management |
| 6 | Smart Debt Split & Settlement | Split Bill, View Debt Board, Send Reminder, Mark Paid |
| 7 | Budget Planning & Alerting | Set Budget Limits, Visual Alerts at 80%/100% |
| 8 | Financial Reporting & Analytics | Interactive Charts, Group Trip Summary, Export PDF/Excel |
| 9 | Savings Goal Management | Set Savings Goal, Track Progress |
| 10 | System Administration | Manage Users, Manage Categories, View Dashboard |

## File Naming Convention

```
UC[XX]_[ShortName].md
```

Example: `UC01_UserRegistration.md`
