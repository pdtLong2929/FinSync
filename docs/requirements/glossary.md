# Glossary

> *Performed by: [Name] | Reviewed by: [Name] | Edited by: [Name]*

| Term | Definition |
|---|---|
| **Wallet** | A bookkeeping account (cash, card, bank) used to track a user's balance. Does not connect to a real bank account. |
| **Transaction** | A record of income or expense associated with a wallet and category. |
| **Category** | A classification label for transactions (e.g., Food, Transportation, Salary). Can be default (system) or custom (user-created). |
| **Group** | A collection of users who share expenses. Each group has an Owner and Members. |
| **Shared Wallet / Group Fund** | A wallet belonging to a group, independent of members' personal wallets. |
| **Owner** | The user who created a group. Has full management permissions. |
| **Member** | A user who joined a group via invitation. |
| **Debt Split** | The process of dividing a group expense among members using equal, percentage, or custom amount methods. |
| **Debt Board** | A summary view showing "who owes whom" within a group. |
| **Settlement** | The act of marking a debt as paid. Payments are made outside the app; the system only records the status. |
| **Budget** | A spending limit set by a user for a specific category over a time period (weekly/monthly). |
| **Savings Goal** | A financial target with a target amount and deadline that users aim to achieve. |
| **JWT (JSON Web Token)** | A compact, URL-safe token used for authentication between the mobile app and the API server. |
| **AI Financial Advisor** | An AI-powered feature that analyzes spending history and suggests budget optimizations. |
| **Regular User** | An end-user who uses the mobile app for personal finance and group expense management. |
| **Administrator** | A system admin who uses the web admin panel to manage users, categories, and view statistics. |
| **Bookkeeping** | Manual financial record-keeping. The system records transactions entered by users — it does not auto-detect or auto-deduct funds. |
| **Receipt Photo** | An image of a receipt/invoice that can be attached to a transaction for reference. |
