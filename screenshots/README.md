# Screenshots

This directory stores screenshots for documentation and reports.

## Subdirectories

| Directory | Purpose |
|---|---|
| `app/` | Application screenshots (mobile app, admin web) |
| `jira/` | Jira board screenshots for weekly reports |
| `git/` | Git log & contribution screenshots |

## File Naming Convention

```
[Category]_[Description]_YYYY-MM-DD.png
```

Example: `Jira_Sprint1Board_2026-10-15.png`
