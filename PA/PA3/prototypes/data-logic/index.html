DL-COMMON — Reusable dialogs and recovery states

DL-C01 · Common flow C1

Cancel or discard

Draft has not been committed

Keep editing, or discard this draft. Already confirmed records are not undone by Back.

Keep editing

DL-C02 · Common flow C2

Session / access changed

Session expired or permission revoked

Stop the protected action. Sign in again when permitted; do not expose data through stale permissions.

Sign in

DL-C03 · Domain validation branches

Input validation

Highlight invalid values and permitted range

Retain valid input and identify what must be corrected. Missing rates or sources are not replaced by invented values.

Correct input

DL-C04 · Common flow C3

Record changed

Current values differ from the reviewed values

Refresh, compare changes and confirm again. Do not silently overwrite newer values.

Refresh and review

DL-C05 · Common flow C4

Result not yet confirmed

Connection or service failure

Check the existing request outcome before retry. Show Pending or Failed until a confirmed result is known.

Check status / retry

DL-C06 · Common flow C5

Already processed

The same request has already completed

Open the existing result. Do not post another transaction, claim, report or alert for the same logical action.

Open result
