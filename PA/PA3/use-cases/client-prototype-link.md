## Scope

The Figma file includes four primary FinSync mobile screens using the approved Liquid Metal visual style:

1. **Overview** — Personal financial summary and recent transactions.
2. **Wallets** — Personal wallet list and wallet-related actions.
3. **Groups** — Shared expense groups and group expense summary.
4. **Reports** — Spending analysis, comparison charts, and category breakdowns.
